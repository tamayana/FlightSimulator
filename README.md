## 🔥 FITUR GILA

| Fitur | Keterangan |
| :--- | :--- |
| 🌍 **Open World 3D** | Terrain berbukit, laut, 120 awan, 50 gedung kota |
| 🌙 **Day / Night Mode** | Pencet `N`, langit jadi malem + 8000 bintang |
| 🤖 **Autopilot** | Pencet `SPACE`, pesawat jalan sendiri |
| ⛽ **Real Fuel System** | Bensin beneran abis! Kalo abis, mesin mati |
| 🌪️ **Real Physics** | Ada Gravity, Drag, Lift, Wind + Turbulence |
| 🧭 **Full HUD** | Speed, Altitude, Heading, Pitch, Roll, Compass, Minimap |
| 🎛️ **Analog Gauges** | Jarum RPM, Speed, VSI gerak real-time |

## 🕹️ CARA MAIN

[W] / [S]  - Naikin / Turunin Throttle (Gas)

[A] / [D]  - Belok Kiri / Kanan (Roll)

[↑] / [↓]  - Naik / Turun (Pitch)

[Q] / [E]  - Putar Kiri / Kanan (Yaw)

[SPACE]    - Autopilot ON / OFF

[N]        - Ganti Siang / Malem

[R]        - Reset Posisi


[ESC]      - Pause


### 💡 Tips Pilot Pemula:
1. Throttle di 70% dulu biar stabil
2. Jangan langsung belok tajem, nanti stall
3. Pake Autopilot kalo mau santai sambil liat pemandangan
4. Jangan sampe Fuel 0% di tengah laut!
